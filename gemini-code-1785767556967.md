# 📄 PRD: MCP Cross-Session Memory Server (Golang Edition)

- **Product Name:** `mcp-shared-memory-go`
- **Language/Runtime:** Go (Golang 1.22+)
- **Primary Dependency:** `github.com/mark3labs/mcp-go`, `modernc.org/sqlite` (Pure Go)
- **Protocol:** Model Context Protocol (MCP) via `stdio`
- **Target Storage:** SQLite (`~/.mcp-shared-memory/db.sqlite`)

---

## 1. Context & Objectives

### Problem
Saat berpindah kerja dari **Google Antigravity** ke **Claude Code** (atau sebaliknya):
- Konteks proyek, riwayat bug fix, dan keputusan arsitektur terputus (*context loss*).
- Pengguna harus menjelaskan ulang *state* terakhir secara manual.

### Solution
Membangun satu executable binary tunggal berbasis **Golang** yang bertindak sebagai **MCP Memory Server**. Server ini menggunakan SQLite lokal untuk menyimpan fakta, entitas kode, dan ringkasan sesi (*handover log*) yang dapat dibaca dan ditulis oleh agen manapun secara real-time.

---

```

## 3. Database Schema (SQLite)

```sql
CREATE TABLE IF NOT EXISTS sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_path TEXT NOT NULL,
    summary TEXT NOT NULL,
    next_steps TEXT,
    files_modified TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS knowledge_nodes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    project_path TEXT NOT NULL,
    entity TEXT NOT NULL,
    category TEXT NOT NULL,
    fact TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

```

## 4. MCP Tools Specification

Server Golang ini menyediakan 4 MCP Tools utama:

| Tool Name | Parameters | Input Description | Function |
| --- | --- | --- | --- |
| `save_session_handover` | `project_path` (req), `summary` (req), `next_steps` (opt), `files_modified` (opt) | Detail status sesi sebelum berganti AI | Menyimpan checkpoint ringkasan sesi ke tabel `sessions`. |
| `get_session_handover` | `project_path` (req) | Path repositori proyek | Mengambil ringkasan sesi paling terakhir dari tabel `sessions`. |
| `store_knowledge` | `project_path` (req), `entity` (req), `category` (req), `fact` (req) | Entitas/keputusan penting | Menyimpan entitas atau keputusan arsitektur ke `knowledge_nodes`. |
| `query_knowledge` | `project_path` (req), `query` (req) | Kata kunci pencarian | Mencari entitas/fakta terdaftar berdasarkan nama entitas/kategori. |

## 5. Agent Integration Rules (Prompt Instructions)

Agar sinkronisasi berjalan otomatis tanpa perlu Anda perintah manual setiap saat, tambahkan instruksi ini ke file aturan agen (seperti `.claude/CLAUDE.md` atau aturan instruksi Antigravity):

```markdown
## Shared Memory Protocols (MCP)
- **Start of Session:** Panggil MCP tool `get_session_handover` dengan `project_path` saat ini untuk membaca apa yang dikerjakan oleh agen sebelumnya.
- **During Session:** Jika ada keputusan arsitektur atau perubahan dependensi penting, panggil `store_knowledge`.
- **End of Session / User Handoff:** Panggil `save_session_handover` untuk merangkum apa yang sudah diselesaikan dan apa langkah berikutnya.

```
